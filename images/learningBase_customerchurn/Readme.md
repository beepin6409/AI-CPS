This Docker image was created as part of the course  
**M. Grum: Advanced AI-based Application Systems**  
by the Junior Chair for Business Information Science, esp. AI-based Application Systems,

## Purpose
This image provides training and validation data for a customer churn prediction task.

## Data Origin
The dataset is derived from Kaggle : https://www.kaggle.com/datasets/sonalshinde123/customer-churn-prediction-dataset  
preprocessed and split into training and test sets.
