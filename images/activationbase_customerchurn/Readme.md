# activationBase_customer_churn

Owner: Bipin Ghimire, Paul Bakos

This Docker image was created as part of the course  
**M. Grum: Advanced AI-based Application Systems**  
by the Junior Chair for Business Information Science, esp. AI-based Application Systems,  
University of Potsdam.

## Purpose
This image provides a single activation data instance used to apply a trained
customer churn prediction model.

## Data Origin
Customer Churn Prediction Dataset (Kaggle): https://www.kaggle.com/datasets/sonalshinde123/customer-churn-prediction-dataset
preprocessed and sampled from the test dataset.
